# Security policy

## Reporting a vulnerability

Email [support@i.ultramcp.com](mailto:support@i.ultramcp.com). Include the steps that show the issue, the version you used, and how to reach you.

Please use that address for security reports. A public GitHub issue can expose the details before a fix is ready.

## What this repository contains

This repository is the install package for the Ultra plugin. The MCP server runs at `https://www.ultramcp.com/mcp`. Each person signs in with OAuth. The package contains no API keys, tokens, or other secrets.

Supported version: 1.0.x.
